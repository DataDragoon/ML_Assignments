## Getting Started

1. Open the relevant assignment PDF for its requirements.
2. For assignments with a notebook, open the `.ipynb` file in Jupyter Notebook, JupyterLab, or VS Code with the Jupyter extension.
3. Run the notebook cells in order. Keep each notebook alongside its assignment data, and update any data paths in the notebook if they point to a location specific to another computer or environment.

Python package requirements may differ between assignments. No shared dependency file is included, so install the packages imported by the notebook you are running.
